# Project Status and Authorship

**Project:** E-commerce Customer Analytics - Pure SQL Edition  
**Author:** Shubham Patil  
**Technology:** PostgreSQL and SQL

## Work Included

This repository contains the SQL implementation for:

- Schema review and indexing strategy
- Monthly cohort retention
- Customer lifetime value
- RFM segmentation
- Churn flagging
- Growth trends and `ROLLUP` summaries
- Query optimization methodology

It also includes a small deterministic seed dataset for local smoke testing.

## Reproducibility Status

The SQL files and setup scripts are present. Full PostgreSQL execution and Olist-scale results require a PostgreSQL installation and the Olist dataset. The repository intentionally does not claim benchmark values or business insights that have not been measured from a loaded database.
